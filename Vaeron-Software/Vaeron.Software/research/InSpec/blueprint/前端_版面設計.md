# 前端 版面設計（VaeronInSpecDemo）

依 `前端_需求單.md`（FR/NFR/C）＋查閱現代風格結果設計。版面由我研究設計（使用者授權）。

## 風格決策
- 用 **.NET 9 內建 Fluent 主題**：`App.xaml` 設 `ThemeMode="System"` → Win11 外觀（圓角、系統強調色、自動淺/深色），零第三方依賴（符合「不多吃環境」）。
- 在 XAML 設 `ThemeMode`（非 code）→ 不觸發實驗性 `WPF0001`，不需 `NoWarn`。
- 來源：MS Learn「What's new in WPF .NET 9」、dotnet/wpf `using-fluent.md`。

## 版面（單頁 NFR-1；橫向三欄任務流,使用者選定;排除直式/四格/左導覽）
```
┌ 狀態列(常駐): InSpec PID··· · 已注入 · 隱藏中   [掃描][無畫面啟動] ┐
├──────────────┬──────────────┬───────────────────────────────────┤
│ ① 選程式      │ ② 執行        │ ③ 結果（AutoExport 匯出檔）        │
│ 目錄[__][瀏] │ 提示值[____] │ 欄1  欄2  欄3  欄4                 │
│ 關鍵字[][查] │              │ ┌───────────────────────────────┐ │
│ ┌清單──────┐│ ▐開始量測▌   │ │ (DataGrid,填滿)               │ │
│ │○ prog1   ││  ←主動作     │ │                               │ │
│ │○ prog2   ││              │ └───────────────────────────────┘ │
│ └──────────┘│ 訊息…        │ 欄位語意待驗證定版                 │
├──────────────┴──────────────┴───────────────────────────────────┤
│ ▸ 進階/展示能力(Expander)      │ ▸ 運作記錄 Log(Expander)[開檔]    │  底列左右並排
└──────────────────────────────────────────────────────────────────┘
```
三欄寬 1:1:1.4(結果較寬);每欄卡片內用 Grid,清單/表格填滿剩餘高度。底列進階與 Log 兩個 Expander 左右各半。

## 元件 → 需求對應
| 區 | 元件 | FR |
|---|---|---|
| 狀態列 | 連線/注入/隱藏狀態、掃描、無畫面啟動 | FR-1 |
| ① | 目錄+關鍵字查詢、結果清單選取 | FR-2 |
| ② | 提示值輸入、開始量測(iscmd+AutoExport+隱藏)、InSpec 摘要面板前端改造(啟用開關＋完成小圖示樣式/顏色) | FR-3、FR-5、FR-6 |
| ③ | 匯出資料表格 | FR-4 |
| 進階 | 即時讀畫面切換 | FR-7 |
| Log | 即時 log + 開檔 | FR-8 |

## 狀態規則（C 干擾約束 → UI 強制行為,不只文件；`條件 → UI`）
| 約束 | UI 行為 |
|---|---|
| C-1 | 「開始量測」執行中 → 進階「legacy 工具列驅動」`IsEnabled=false`;反之執行中鎖開始量測 |
| C-2／C-4 | InSpec 隱藏中 → 「即時讀畫面」toggle `IsEnabled=false`（tooltip：需視窗可見）;「即時讀畫面」開啟中 → 「隱藏視窗」`IsEnabled=false` |
| C-3 | 「開始量測」執行中 → 暫停 GDI 讀畫面 timer,結束後恢復 |
| C-5 | 前端改造(完成小圖示＋就地編輯欄位)/Demo/LiveEdit 按鈕共用監看執行緒(DLL 內部,無 UI 衝突,不需鎖) |

## 已知限制
- ✗ 結果表格欄位(元素/值/公差/判定)對映匯出檔真實欄位的解析,待有非空匯出檔(真機台/有量測元素程式)才能定版;目前先以「每行原樣」＋預留欄位呈現。
