資安與治理

本頁為安全部署的運維建議參考；實際規範仍以貴司政策及合約要求為準。

角色與權限

建議將操作員使用與管理性動作明確區分。以下動作宜要求較高權限或核准流程：

  • 工作區建立、修改與刪除
  • 模組安裝與移除
  • 事件日誌匯出
  • 設定變更（尤其是影響所有使用者的系統設定）

資料處理

事件日誌與截圖可能包含操作記錄、識別資訊或業務數據，應視為潛在敏感資料。

  • 日誌匯出檔案請存放於 IT 核准的位置，並套用適當的存取控制與保留政策。
  • 依貴司政策決定保留天數與是否允許使用者自行匯出。

截圖外洩風險

在工單或訊息中附加截圖時，請使用指定視窗截圖而非全螢幕，並依規範遮蔽敏感欄位（如識別碼、資料值）後再發送。

離線說明內容

本說明隨程式一同安裝，以本機 HTML 檔案形式提供，不需要網路連線，適合不允許連外網的封閉環境部署。說明內容為靜態唯讀，無法在此頁面傳輸任何資料。

合規證據

若採購或稽核流程需要資安或合規文件（例如滲透測試報告、SOC 認證或系統文件），請透過供應商支援管道提出申請，並將取得的文件存放於貴司治理系統中集中管理。

版本對應

申請合規文件時，請一併提供主程式版本號（設定 → 關於），以確保供應商提供的文件與實際部署版本一致。
