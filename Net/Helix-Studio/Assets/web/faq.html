Help

常見問題與支援

如何更換介面顏色（主題）？

前往 設定 → 顯示 → 介面主題，從下拉選單選擇主題，即時套用。

如何切換工作區？

點選視窗左上角的工作區名稱，在彈出選單中選擇目標工作區即可切換。

在哪裡找到版本編號？

前往 設定 → 關於，或直接查看視窗底部狀態列的右側區域，均可看到建置版本識別碼。

安裝模組後，左側導覽沒有出現？

安裝後模組預設為停用狀態。請至 SYSTEM → Modules，選取該模組後點選 開啟模組，載入後導覽才會出現對應項目。

設定或工作區選項無法修改，呈現灰色？

此為正常的權限行為。企業部署環境中，部分設定由 IT 政策鎖定；若有異議，請洽貴司資訊單位確認您的帳號權限。

Ctrl + K 沒有反應？

此快捷鍵可能被其他程式（輸入法、遠端桌面、截圖工具）攔截。請先確認主視窗已取得焦點，並嘗試暫時關閉衝突軟體確認問題來源。詳細說明請見疑難排解。

如何提交支援工單？

請透過貴司內部 IT 支援管道，或合約指定的供應商支援流程。提交時請附上：

  • 版本/建置識別（設定 → 關於 或狀態列）
  • 裝置識別與工作區名稱
  • 發生時間區間（含時區）
  • 事件日誌匯出（若政策允許）
