快捷鍵與搜尋

鍵盤快捷鍵

快捷鍵 功能
Ctrl + K 聚焦頂欄搜尋欄位並選取現有內容，可直接輸入關鍵字
Esc（搜尋有焦點時） 清空搜尋欄位內容
↑ / ↓（建議清單開啟時） 移動建議清單的選取列
Enter（建議清單開啟時） 套用目前選取的建議項目，導向對應頁面或設定

快捷鍵衝突

若 Ctrl + K 無反應，可能被輸入法、遠端桌面或截圖工具攔截。詳見疑難排解。

全域搜尋

頂欄中央的搜尋欄位可導向設定分頁或主要功能區。輸入關鍵字後，建議清單會即時出現；選取後按 Enter 確認導向。若無符合結果，畫面不變，請改用左側導覽。

搜尋支援中英文關鍵字，以下為常用範例：

目標 可輸入的關鍵字
首頁 home、首頁
事件日誌 event log、log、日誌
模組 module、modules、模組、擴充、外掛
設定 › 一般 language、介面語言、start page、啟動頁面、inactivity、閒置
設定 › 顯示 theme、主題、font、字型、density、密度
設定 › 工作區 workspace、工作區
設定 › 日誌 log level、記錄等級、retention、保留、export、匯出
設定 › 關於 about、關於、version、license、授權

模組專屬的頁面與功能名稱，請在 Modules 清單或模組本身的介面中尋找，搜尋索引不涵蓋模組自訂頁面。
