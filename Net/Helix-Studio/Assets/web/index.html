主視窗與導覽

Horizon Nova Studio 的介面由五個固定區域組成，以下依區域說明各自的用途。

左側導覽

WORKSPACE 群組 — 首頁（Home）為內建入口；已載入的模組會依序列在首頁下方，點選即可進入對應的模組頁面。

SYSTEM 群組 — 包含三個固定項目：

  • Event Log — 記錄應用程式與模組的事件歷程。
  • Modules — 管理已安裝的擴充模組（安裝、開啟、停用、移除）。
  • Settings — 調整一般、顯示、工作區、日誌與模組設定。

工作區切換

視窗左上角顯示目前作用中的工作區名稱。點選後可切換至其他工作區，或進入工作區管理。

企業部署說明

在受管制環境中，工作區通常由 IT 透過部署設定管理；若選項被停用，屬正常的權限行為。

頂欄

頂欄分為三個部分：

  • 左側 — 顯示工作區名稱與目前頁面的路徑導引。
  • 中央 — 全域搜尋欄位，可用 Ctrl + K 快速聚焦。搜尋說明請見快捷鍵與搜尋。
  • 右側 — 通知鈴鐺與說明按鈕（即本說明）。

通知

點選頂欄右側的鈴鐺圖示開啟通知面板。通知會保留直到您手動清除；面板底部的清除全部按鈕僅在有內容時才會出現。

快訊（Toast）是另一種短暫顯示在內容區右下角的即時提示，幾秒後自動消失，不會存入通知清單。

狀態列

視窗底部的狀態列顯示：目前工作區、模組載入摘要、裝置識別，以及應用程式建置版本。

回報問題時

提交支援工單時，請一併附上狀態列中的版本/建置識別，以及發生時間區間，有助於對照稽核記錄。
