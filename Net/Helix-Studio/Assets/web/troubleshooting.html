疑難排解

說明無法在瀏覽器開啟

本說明為隨程式安裝的本機 HTML 檔案，需要預設瀏覽器才能開啟。

  1. 確認 Windows 已設定預設瀏覽器，且可開啟本機 .html 檔案。

  2. 若防毒或端點防護工具阻擋，請洽 IT 將安裝路徑加入允許清單。

  3. 部分企業環境禁止從應用程式啟動外部程式，此情況需由 IT 調整政策。

快捷鍵或搜尋無反應

Ctrl + K 等快捷鍵可能被其他工具全域攔截，常見來源包括輸入法（IME）、遠端桌面用戶端、截圖軟體，以及資安代理程式。

  1. 確認主視窗已取得焦點（點選主視窗後再嘗試快捷鍵）。

  2. 暫時停用或切換其他工具，確認問題是否消失以定位衝突來源。

  3. 若僅在特定工作站發生，對比其他工作站的已安裝工具清單。

快速確認方法

在主程式按 Ctrl + K，再在其他軟體的輸入框嘗試同一組合鍵。若只有主程式無反應，問題通常出在全域快捷鍵衝突而非主程式本身。

模組載入失敗或功能異常

  1. 前往 SYSTEM → Modules，確認模組狀態為開啟。若顯示載入錯誤，嘗試停用再重新開啟。

  2. 確認模組版本與主程式版本相符；版本號可至 設定 → 關於 查看。

  3. 前往 SYSTEM → Event Log，篩選模組載入相關的錯誤記錄，記下發生時間以利回報。

效能緩慢或頁面載入遲緩

  • 模組數量 — 停用非必要模組，縮小問題範圍。
  • 事件日誌大小 — 若保留的日誌量過大，依政策匯出後清理。
  • 工作站等級 — 在低階硬體上，考慮提高 UI 密度或降低同時開啟的視圖數。

回報問題

提交支援工單時，請附上下列資訊以確保問題可被定位：

資訊取得位置
版本/建置識別 設定 → 關於，或狀態列右側
裝置識別 狀態列
工作區名稱 視窗左上角，或狀態列左側
發生時間區間（含時區） —
事件日誌匯出 SYSTEM → Event Log（若政策允許）

截圖注意事項

附加截圖時，請使用指定視窗截圖方式，避免全螢幕截圖意外包含其他敏感資訊，並依貴司規範遮蔽必要欄位。
