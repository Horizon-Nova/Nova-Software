# InSpecTool

InSpecTool 是 Horizon Nova HN-Studio 的 InSpec 作業模組，用於承接條碼輸入、欄位解析、`.iwp` 檔案查找、InSpec 開檔與自動化輸入流程。

此模組的定位不是單純搜尋器，而是把現場檢測作業會用到的條碼、欄位、輸出目標與 InSpec 操作串成同一條工作流程。

## 主要用途

- 依條碼內容解析出檢測作業所需欄位
- 依欄位結果查找對應的 InSpec `.iwp` 檔案
- 開啟 `.iwp` 後配合自動化流程執行 Run
- 接收 `Input.txt` 內容並寫入對應目標檔案
- 透過模組設定管理欄位結構、查找目錄與自動化行為

## 功能說明

### BarCode 輸入框

1. 接收條碼輸入
2. 依欄位結構解析條碼內容
3. 將解析結果同步到欄位區
4. 依欄位結果查找 `.iwp` 檔案
5. 依欄位結果推算手動輸出目標路徑
6. 將目前目標路徑保存到 `IsolatedStorage`

### 欄位區

1. 顯示目前條碼解析後的欄位值
2. 支援直接修改欄位內容
3. 欄位變更後重新刷新檔案查找結果
4. 欄位變更後重新刷新輸出目標路徑

### 檔案結果區

1. 顯示目前查找到的 `.iwp` 結果
2. 支援手動刷新查找結果
3. 支援雙擊開啟 `.iwp`
4. 依設定決定開檔後是否自動執行 Run

### InSpec 自動化

1. 監聽 InSpec 提示視窗
2. 依欄位設定決定直接輸入或手動確認
3. 支援自動填值
4. 支援開檔後自動執行 Run

### 檔案橋接

1. 保留 `Input.txt` 作為外部輸入橋接入口
2. 使用 `IsolatedStorage` 保存目前輸出目標路徑
3. 偵測 `Input.txt` 內容後，自動附加寫入對應目標檔案
4. 自動建立不存在的資料夾與目標檔案

## 模組設定

### 掃描間隔

- 控制條碼輸入防抖延遲
- 避免每次輸入都立刻觸發完整刷新

### 自動監聽

- 控制是否啟用 InSpec 提示視窗監聽

### 監聽間隔

- 控制自動監聽輪詢頻率

### 搜尋目錄

- `.iwp` 檔案查找根目錄

### 系統記錄目錄

- 手動輸出內容對應的主輸出目錄

### 備份輸出目錄

- 補充輸出或備援輸出目錄

### 自動執行 Run

- 控制開啟 `.iwp` 後是否自動執行 Run

### 欄位結構

- 管理欄位名稱
- 管理欄位關鍵字
- 管理欄位目標模式
- 管理欄位是否可編輯

## 匯入檢查

本模組採用 Helix-Studio SDK 新格式：身分與圖示由組件中繼資料與內嵌資源提供，**不**再使用 `module.json`。從專案建置後的 `PackageOutput\InSpecTool` 導入時，根目錄需至少包含建置產生之 `InSpecTool.dll` 與 `InSpecTool.deps.json`（`Helix-Studio.ModuleSdk.dll` 由宿主主程式提供，模組包內不需放）。

## 備註

- 此模組需搭配可正常開啟 `.iwp` 的 InSpec 環境使用
- 模組外觀與色系會跟隨 HN-Studio 宿主主題
- 模組設定頁由模組自行提供，但樣式依宿主資源統一
