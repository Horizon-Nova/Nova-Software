# 藍圖：平台資料庫（讀取全部交給 vw_）

2026-10-13

規則：`.claude/rules/Rules.md`、`SQL_Design.md`。
使用者原話：「先做好資料庫的穩定」「如果按照我說的做且沒有錯你的Code應該會很輕基本上不會有任何東西」。

## 1. 現況（盤點結果）

- 程式從資料列推導東西的地方約 60 處，集中在 `ShellLogic`、`CatalogLogic`、`DetailLogic`、`PaletteLogic`、`SettingsLogic`，以及 InSpecTool 的 `Measure`、`Setup`。
- `vw_shell` 把工具、裝置、人、搜尋字四種列 UNION 在一起，沒有過濾、計數、格式化；程式再用 `type ==`、`state ==` 分開、自己數、自己拼句子。
- 狀態對文字、顏色、圖示的對照表寫死在 C#（`StateText`、`StateInk`、`ActionText`…）。
- 已經照規則的：`vw_key`（次數、時刻文字、到期日）、`vw_inspec` 的 `elapsed_ms`、`started_text`。

## 2. 改成什麼

一支 view 一個讀取形狀，兩種查詢：單一（Item）與列表（Items）。程式只把欄位擺上畫面；固定的字寫在 XAML。

| 新的 view | 一列是什麼 | 帶出的欄位（全部在 view 算好） | 取代程式裡的 |
|---|---|---|---|
| `vw_tool` | 一支工具 | 代碼、名稱、圖示、分類、維護團隊、版本文字（`v1.1.7` 或 `1.1.6 → 1.1.7`）、狀態代碼、是否已裝、是否可更新、說明、能力／權限／更新日誌（攤成列表）、更新日期文字、掛載資訊、設定型別、側欄順序 | `type == "tool"` 過濾、`Installed` 集合、版本字串、日期格式 |
| `vw_shell_summary` | 只有一列 | 已安裝幾支、共幾支、可更新幾支、套件庫最後匯入時刻文字 | 狀態列與工具目錄標題的所有計數 |
| `vw_category` | 一個分類 | 分類名稱、工具數；「全部」也是一列 | 分類標籤的 Distinct 與計數 |
| `vw_search` | 一個搜尋字 | 字、最後用到的時刻；新的在前 | `type == "search"` 過濾 |
| `vw_setting` | 一項設定 | 現有欄位，加上「是否改過」（`value <> fallback`）、各區段的設定數 | `moved`、`Count`、分組 |
| `vw_key` | 一支工具 | 已完成 | — |
| `vw_inspec_setting` | 只有一列 | 每項設定一欄：搜尋資料夾、紀錄資料夾、備份路徑、條碼解析間隔、跑完顯示結果、左欄寬度 | `type == "setting"` 過濾與字典 |
| `vw_inspec_field` | 一個欄位 | 名稱、提示、填法、主頁可改、順序 | `type == "field"` 過濾 |
| `vw_inspec_run` | 一次執行 | 現有欄位，加上「花了多久」文字（`0.6 秒`）、是否歸檔 | `elapsed_ms/1000` 格式化 |

### 使用者輸入當條件

搜尋框打的字、選的分類，是查詢條件：程式把它當參數帶進 `vw_tool`、`vw_category` 的查詢（WHERE），計數仍由資料庫做（同一支查詢的 GROUP BY），程式不自己數。

### 狀態的文字、顏色、圖示

不再放 C# 對照表。view 帶出狀態代碼，XAML 依代碼換文字、顏色、圖示（固定的字寫在標記裡）。

### 拿掉的固定界線

照「值不畫線」：

| 現在 | 改成 |
|---|---|
| 最近搜尋只取 4 筆（`Remembered = 4`） | 全部列出，新的在前，看幾個由看的人決定 |
| 指令面板最近只取 3 筆（`Recent = 3`） | 同上 |
| 席次超過 90% 才變色（`Crowded = 90`） | 見第 3 節 |

## 3. 沒有資料來源的功能：請決定

假資料刪掉之後，下面這些功能已經沒有任何資料會來，現在只剩空殼：

| 功能 | 原本靠什麼 | 現在 |
|---|---|---|
| 使用資格（「你符合使用資格」「申請授權」） | 假使用者的角色 `roles`、工具的 `audience` | 沒有使用者資料 |
| 席次與使用量分頁 | `seats` 欄位 | 匯入時寫死 `1/1` |
| 怎麼用分頁（操作說明、維護人、內線） | `guide` 欄位 | 空 |
| 合規狀態、必裝提醒泡泡 | `required` 欄位 | 沒有任何必裝工具 |
| 徽章數字 | `badge` 欄位 | 永遠 0 |
| 需主管核可 | 設定 `updateNeedApproval` | 沒有核可流程 |

## 4. 順序

1. 這份藍圖確認
2. 寫 view（init＋migrate），列進 BuildModels，產生模型
3. 程式改讀新的 view，刪掉 C# 裡的過濾、計數、對照表
4. 實機檢查每一個畫面數字跟改之前一樣
5. 繼續查啟動那 5 秒
