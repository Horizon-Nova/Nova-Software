## 1. 使用者定的（原話）

| 項目 | 原話 |
|---|---|
| 是什麼 | 「Helix Studio 除了本身的金鑰還有一個工具金鑰」「看這把鎖他配不配得上」 |
| 形式 | 「和金鑰一樣是一串代碼」 |
| 綁定 | 「和金鑰一樣電腦」 |
| 開工具 | 「開工具也要工具金鑰」「匯入工具後想要啟用工具就要輸入一次」 |
| 工具設定 | 「看設定決定我記得5分鐘會清除key像是Cookie一樣」 |
| 反查 | 「可以從鎖得知你的使用時間、次數、控管」 |
| InSpecTool 解鎖號碼 123 | 「拿掉」 |
| 工具設定歸誰 | 「工具設定並不是 InSpecTool 獨立的設計」 |

## 2. 流程

| 動作 | 誰做 | 結果 |
|---|---|---|
| 發工具金鑰 | 賣方用 `helixpack toolkey <申請碼> <私鑰> <客戶> <工具清單> [到期日]` | 一串代碼；申請碼就是授權畫面那一段（同一台電腦） |
| 啟用工具 | 操作員：匯入工具後，第一次開它時貼上工具金鑰 | 簽章對、電腦對、清單有這支、沒過期 → 這支工具啟用；記一筆「啟用」 |
| 開工具 | 每次開 | 重驗一次存著的那把（跟授權檔一樣每次重驗）；記一筆「開啟」 |
| 進工具設定 | 工程師輸入工具金鑰 | 驗過 → 這支工具的設定解開 N 分鐘，時間到自動清掉；記一筆「解鎖設定」 |
| 反查 | 設定 › 關於本軟體 | 每支工具：啟用時間、開了幾次、最後一次、設定解鎖幾次 |

## 3. 金鑰內容

照授權金鑰的格式（Base64 的 JSON），多一個 `Kind = "tool"`，用**另一組**發證金鑰簽：授權金鑰不能拿來當工具金鑰用，反過來也不行。

| 欄位 | 說明 |
|---|---|
| Kind | 固定 `tool` |
| Customer | 賣給誰 |
| Issued | 發證日 |
| Expires | 到期日；空的是永久 |
| Tools | 這把金鑰配哪幾支工具（tool_no） |
| Marks | 綁的那台電腦的機器識別（同授權） |
| Signature | 簽章 |

## 4. 資料庫（`helix_studio`）

### 4.1 工具金鑰：`dbo.tool` 的 key 列

| type | 一列是什麼 | 用到的欄 |
|---|---|---|
| tool | 一支匯入的工具 | name、icon、version…… |
| key | 啟用時存下的工具金鑰；最新的那一把就是現在用的 | tool_no、code |

### 4.2 使用紀錄：`dbo.event_log`

發生過的事，一件一列，只新增不改寫（照 Vaeron.Web 的 event_log，不記 IP）。

| 要知道的 | 欄位 |
|---|---|
| 什麼時候 | created_at |
| 什麼事情 | type（activate／open／unlock／error）、tool_no |
| 系統處理過程 | function_name、message、stack_trace［error］ |
| 誰 | account：登入 Windows 的帳號 |

### 4.3 平台設定

`setting` 加一項 `toolKeyMinutes`：工具設定解鎖多久。預設 5（使用者原話「我記得5分鐘」）。

## 5. 畫面（先畫設計稿，核准後才做）

| 畫面 | 內容 |
|---|---|
| 啟用工具 | 匯入後第一次開：貼工具金鑰、驗證結果 |
| 工具設定鎖住 | 設定 › 工具 › 某支：鎖住時唯讀，輸入工具金鑰解開，右邊倒數 |
| 使用紀錄 | 設定 › 關於本軟體：每支工具的啟用時間、開啟次數、解鎖次數 |

## 6. 我補的，請確認

| 項目 | 我的做法 | 理由 |
|---|---|---|
| 另一組發證金鑰 | 工具金鑰用自己的私鑰簽 | 授權金鑰與工具金鑰不能互換 |
| 一把金鑰配幾支 | 可以列多支（同授權的工具清單） | 照授權格式 |
| `toolKeyMinutes` 的選項 | 只放 5 | 其他選項沒有來源 |
| 授權檔的准開清單 | 保留，開工具要兩把都過 | 原話沒說拿掉授權檔的清單 |
