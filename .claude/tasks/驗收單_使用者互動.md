# 驗收單：使用者互動（本輪工作範圍）

驗收對象是「操作起來的感受與結果」，不是個別 Function。每一項照順序操作，勾選「符合／不符合」，不符合時記錄實際看到的狀況。

## 一、匯入工具

1. 開啟「工具庫」畫面 → 點匯入 → 選一個 `.exe` 檔案。
   預期：匯入成功，工具出現在工具庫清單中；此時左側「TOOLS」不會出現這個工具（還沒啟動）。
2. 匯入一個 `.zip` 封裝（內含 `tool.json` 與 `Entry` 指向的實際執行檔）。
   預期：解壓縮成功，工具庫清單新增一筆，內容（名稱／分類／說明）取自 `tool.json`。
3. 嘗試匯入一個 `.msi` 或其他不支援的副檔名。
   預期：檔案選取視窗直接篩選不出來，或匯入時明確提示不支援，不會產生殘留資料。

## 二、從「已安裝工具」啟動

4. 到「已安裝工具」畫面，對剛匯入的工具按「啟動」。
   預期：畫面出現啟動中狀態，隨後工具畫面直接嵌入 Helix Studio 的介面中──全程「不會」看到任何獨立浮動視窗，連一瞬間都不會（這是本輪最嚴格的要求，需要特別留意畫面閃現）。

## 三、左側 TOOLS 動態清單

5. 啟動前檢查左側「TOOLS」區塊。
   預期：尚未啟動任何工具時，TOOLS 標題與清單都不顯示（不是顯示空清單，是整區收起）。
6. 完成第 4 步啟動後，再看左側 TOOLS。
   預期：剛啟動的工具出現在 TOOLS 清單中；未啟動、僅是「已安裝」的其他工具不會出現在這裡。
7. 點擊 TOOLS 清單中的工具項目。
   預期：畫面切回該工具的嵌入畫面（聚焦／顯示），不會重新啟動一次、不會另外彈出視窗。
8. 關閉該工具（結束行程）。
   預期：TOOLS 清單中對應項目消失。

## 四、切換畫面

9. 依序點擊側欄每個項目：工作區、已安裝工具、工具庫、事件日誌、設定、USB 電壓控制、遠端批次傳輸，以及至少一個 TOOLS 動態項目。
   預期：每次切換畫面內容立即對應更新，無殘影、無舊畫面內容夾雜新畫面的情形，側欄的選取樣式（強調色／底線）正確跟著移動。

## 五、設定 → 電源（離線真實鏡像）

10. 打開「設定」→ 電源頁籤，記下目前顯示的省電/平衡/高效能等模式與各項數值。
11. 不透過 Helix Studio，直接在 Windows 電源選項中手動改一項設定（例如切換電源模式，或改變螢幕逾時分鐘數）。
12. 回到 Helix Studio 電源頁籤（重新整理或重新進入畫面）。
    預期：畫面顯示的數值與 Windows 當下的真實狀態一致，不是沿用舊快取、也沒有把 Windows 剛才的手動變更覆蓋回去。
13. 反過來，在 Helix Studio 電源頁籤內改一項設定。
    預期：Windows 實際的電源設定同步變更（可用 `powercfg /q` 或系統設定畫面確認）。

## 六、InSpec 量測助手（核心量測流程）

14. 啟動 InSpec 量測助手（比照第二節從已安裝工具啟動）。
    預期：同樣是嵌入顯示，無獨立浮窗。
15. 在左側搜尋區塊瀏覽或篩選出一個 `.iwp` 量測程式。
    預期：檔案清單正確列出，篩選文字即時生效。
16. 點「連接」或「掃描」讓工具嘗試連上 InSpec 主程式。
    預期：連線狀態列正確反映目前狀態（掃描中／已連線／啟動失敗等），有對應的顏色與文字。
17. 選定 `.iwp` 後按「執行」。
    預期：右側結果表格顯示量測結果；尚未執行時顯示「尚無結果」提示而不是空白一片。

## 七、視覺風格一致性

18. 交叉比對 Helix Studio 本體與 InSpec 量測助手兩邊的按鈕、輸入框、卡片邊框、字型、配色。
    預期：兩邊視覺風格一致（因為共用同一份樣式來源），InSpec 端沒有另外一套自己的配色或字型。

---

以上任一項「不符合」，請直接描述實際看到的畫面或行為，不需要指出是哪個 Function 造成的。
