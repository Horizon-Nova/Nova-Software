## 1. 掃條碼

操作員掃描或貼上條碼，欄位自動填好。

| # | 需求 | 狀態 |
|---|---|---|
| 1.1 | 條碼以 `\|` 分段，依序填入欄位；開頭的 `\|` 去掉 | 舊版 |
| 1.2 | 條碼含 `_` 就擋下，顯示「條碼格式不正確，包含不允許的字元。」 | 舊版 |
| 1.3 | 料號整理：轉大寫，最後一個 `-` 之後只留開頭的連續字母（`AB1-C45` → `AB1-C`）；找檔用 | 舊版 |
| 1.4 | 停止輸入後等「條碼解析間隔」才解析；間隔留成設定（舊版預設 80 ms，可選 80/120/160/200/300/500） | 已定：要 |
| 1.5 | 改任一欄位，反過來組回條碼 `\|v1\|v2\|…\|` | 舊版 |
| 1.6 | 畫面載入或回到這頁時，條碼框自動取得焦點並全選 | 舊版 |

預設欄位（舊版）：

| 欄位 | 對應提示 | 可編輯 | 模式 |
|---|---|---|---|
| 料號 | part number | 是 | 直接填 |
| 批號 | lot number | 是 | 直接填 |
| 壓合 | press | 否 | 先確認再填 |
| 機台 | machine | 是 | 直接填 |
| 操作員 | operator | 是 | 直接填 |

## 3. 執行量測（雙擊一個 .iwp）

| 3.2 | 檔案不存在或只有 2 bytes（空程式）就停下並說明 | 舊版 |
| 3.3 | 記下這次執行的料號、批號、壓合，跟著這次執行走 | 推論 |
| 3.4 | 複製一份 .iwp 當執行副本，原檔不動 | 已驗 |
| 3.5 | 副本的自動匯出指到這次專用的檔，並打開（`Enab 1`） | 已驗 |
| 3.6 | 副本的匯出改成 Unicode（`Unicode 1`）；中文介面不開會整段變 `ERROR` | 已驗 |
| 3.7 | 副本保持 CRLF 換行；LF 會讓 InSpec 跳「Unexpected file format」 | 已驗 |
| 3.8 | InSpec 沒開就啟動它；主視窗保持顯示，不藏 | 已驗；已定：不藏 |
| 3.9 | 用 `iscmd /run 副本`（不加 `/nowait`）開檔並執行 | 已驗 |
| 3.10 | InSpec 出現輸入提示時，由 Windows 通知，不輪詢、不看前景 | 已驗 |
| 3.11 | 讀提示文字（控制項 1278），比對是哪個欄位 | 已驗 |
| 3.12 | 模式「先確認再填」的欄位先跳視窗讓操作員確認，再填 | 舊版 |
| 3.13 | 填值：打字型填輸入框 499；清單型選 1269；下拉型選 1297 | 打字型已驗，清單和下拉推論 |
| 3.14 | 送標準確定（編號 1），不看按鈕文字 | 已驗 |
| 3.15 | 提示對不上任何欄位、或欄位是空的，就不填，告訴操作員是哪個提示 | 推論 |
| 3.16 | iscmd 回來＝InSpec 跑完；**跑完才歸檔** | 已驗（只有提示、沒量測元素的程式）；已定 |

| 3.18 | 歸檔寫入系統紀錄資料夾失敗時，改寫到備份輸出路徑 | 已定 |
| 3.19 | 歸檔完顯示這次的結果；結果畫面左下角有一個勾選框，操作員決定下一次要不要顯示 | 已定 |
| 3.20 | InSpec 跳出錯誤視窗時，讀出內容告訴操作員 | 推論（有偵測到錯誤視窗，還沒讀文字） |
| 3.21 | 每一次執行都記進資料庫：誰、哪個檔、欄位值、開始與跑完的時刻、匯出內容、歸檔到哪裡 | 已定：資料庫照 rules 設計 |

歸檔路徑（舊版規則）：
`{系統紀錄資料夾}\{壓合第一個 - 之前}\{料號第一個字}\{料號 - 前段}-{後段第一個字}\{料號}_{批號}.txt`
寫入失敗時同樣的相對路徑改放在備份輸出路徑底下（3.18）；料號、批號、壓合任一缺少就不歸檔。

**不處理**：操作員自己在 InSpec 裡按執行、或直接開別的 .iwp 跑。這是操作員處理特殊情況（手動跑不同料號或編碼）的方式，InSpecTool 不介入、不歸檔。

## 6. 淘汰的舊做法

| 舊做法 | 原因 |
|---|---|
| 用作業系統監看 `C:\InSpecTool\Input.txt` 有沒有寫入，決定歸檔 | 由 iscmd 回來判斷跑完；匯出檔每次專用，操作員碰不到，不會誤觸 |
| `current-target.txt`（更早期的做法） | 同上 |
| 掃選單文字找「執行」、等 5 秒再送命令 | iscmd 直接開檔並執行，不靠選單 |
| 用系統關聯開 .iwp、失敗開檔案總管 | 同上 |
| 每 500 ms 看前景視窗有沒有提示 | 改由 Windows 通知 |
| 取對話框最長的文字當提示、找「OK／確定」按鈕 | 改用控制項編號，不看文字，不受語言和版本影響 |
| 600 ms 內不重複的防呆 | 每個對話框只通知一次 |
| 設定「監控輪詢間隔」「啟用自動監控」 | 沒有輪詢了 |
| 設定「啟用自動開啟」 | iscmd 開檔就是執行 |
| 主頁「自動監控：開啟（N ms）」狀態列 | 同上 |
| 模組自己的金鑰對話框 | 改由 HelixStudio 授權 |
| 注入 DLL 到 InSpec | 這張需求單的功能都從外部做到了，不需要注入 |
| 「備份輸出路徑」只在系統紀錄資料夾空白時替代 | 改成主要路徑寫入失敗時才用（3.18） |
| 設定存在宿主的設定檔 | 改存資料庫（4.6） |
